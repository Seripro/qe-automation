# QE Web GUIのための学習ロードマップ

## このロードマップの目的

GUIを実装する前に、「何を計算し、入力値が何を意味し、出力をどう読めばよいか」を説明できる状態を目指す。数式の厳密な導出を最初の目標にはせず、QEでの操作と物理的な意味の対応を優先する。

## 学ぶ順序

### 1. 第一原理計算とDFT

- 原子の種類と配置から、電子状態や全エネルギーを近似的に求める目的
- 密度汎関数理論（DFT）が電子密度を中心に扱う理由
- QEがDFT計算を行うソフトウェアであること

**GUIとの関係:** ユーザーが入力する結晶構造と計算条件が、どの物理量に影響するかを説明する土台になる。

### 2. 結晶構造、逆格子、k点

- 結晶の周期性と単位胞
- 電子状態を波数（k）で分類する考え方
- k点メッシュと高対称k点経路の用途の違い

**GUIとの関係:** 構造の選択、SCF用k点メッシュ、バンド構造用k点パスを別々に扱う理由を理解する。

### 3. SCF計算

- 電子密度を仮定して電子状態を解き、更新を繰り返す自己無撞着場（SCF）
- 収束とは何か、収束しないと何が問題か
- SCF出力から確認する値（全エネルギー、フェルミ準位、収束状況）

**GUIとの関係:** 計算進捗、収束失敗の表示、ログの要約に必要になる。

### 4. QE入力ファイル

- `&CONTROL`、`&SYSTEM`、`&ELECTRONS` の役割
- `ATOMIC_SPECIES`、`ATOMIC_POSITIONS`、`K_POINTS`、格子情報
- 擬ポテンシャル、平面波カットオフ、占有方法

**GUIとの関係:** どの項目をフォームとして公開し、どれを初期値・詳細設定にするかを判断する。

### 5. 収束試験

- `ecutwfc` とk点メッシュを十分な精度まで増やす理由
- 計算コストと精度のトレードオフ
- 全エネルギーなどを用いた収束性の確認

**GUIとの関係:** 初学者向けの推奨値、警告、将来の収束試験支援機能の根拠になる。

### 6. バンド構造

- バンドがエネルギーとkの関係を表すこと
- 高対称経路に沿って描く目的
- フェルミ準位、金属・半導体、バンドギャップの基本的な読み方

**GUIとの関係:** バンド図の軸、基準エネルギー、k点ラベルを正しく表示する。

### 7. DOSとPDOS

- 状態密度（DOS）が表す量
- 投影状態密度（PDOS）で原子・軌道の寄与を見る目的
- バンド構造との補完関係

**GUIとの関係:** グラフの系列選択、凡例、結果の説明を設計する。

## 最初の到達目標

シリコンを対象に、既存または準備した `pwscf.in` を読み、次の流れを自分の言葉で説明できるようにする。

1. 構造・擬ポテンシャル・計算条件を入力する。
2. SCF計算で自己無撞着な電子状態を求める。
3. バンド用のk点パスに沿って後続計算を行う。
4. バンド図をフェルミ準位との関係で読む。

分からない用語や判断は、そのまま疑問として記録する。理解したと推測して補完しない。
