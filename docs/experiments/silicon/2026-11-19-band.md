# シリコン基準入力のバンド構造計算

- 実施日: 2026-11-19
- 状態: バンド計算・データ生成・図の生成が正常終了。物理的妥当性は未検証。
- 対象物質: Si
- 前段: [シリコン基準入力のSCF計算](2026-11-19-scf.md)

## 目的

SCFで得た電子密度と再始動データを用い、高対称k点経路上のKohn–Sham固有値を計算し、バンド図の元データを得る。

## 実行環境・入力

- ホスト: `ubuntu2404`（`mdx-server`）
- QE: `~/program/q-e-7.6/bin/pw.x`、`bands.x`
- 実行方式: OpenMP 4スレッド、PBS・MPIなし
- SCF作業ディレクトリ: `~/work/Si-scf-2026-11-19-run1/PWscf/`
- SCFのKohn–Sham状態数: 8
- `nbnd`: 16（既存スクリプトの「状態数の2倍」という設定を引き継いだ）
- k点経路: SeeK-pathで自動生成、各区間20点
- フェルミ準位: 6.4775 eV（SCF出力から取得）

## 使用コマンド

```bash
source ~/.venvs/qe-tools-v1/bin/activate
bash scripts/qe_mdx_band_openmp.sh \
  ~/work/Si-scf-2026-11-19-run1
```

`numpy` と `seekpath` はユーザー専用のPython仮想環境 `~/.venvs/qe-tools-v1/` に導入した。

## 生成したk点経路

```text
Gamma → X → U | K → Gamma → L → W → X
```

`|` は経路が不連続になる箇所を表す。実際のQE入力は `kp.pwscf` に `K_POINTS {crystal_b}` 形式で保存された。

## 結果の読み取り

`bands.out.gnu` は、横軸の累積k点距離と、各バンドの固有値（eV）からなるプロット用データである。バンド図では通常、SCFから得たフェルミ準位 6.4775 eV を各固有値から引き、フェルミ準位を0 eVとして表示する。

この計算が正常終了したことは、バンド図の物理的妥当性を保証しない。`nbnd = 16` が十分な非占有バンドを含むか、k点経路・入力条件が目的に適切かは、図を確認してから判断する。
