# QE Web GUI 要件の整理

## 研究目的（暫定）

Quantum ESPRESSOを用いた基本的な電子状態計算について、初学者が計算の投入、進捗確認、結果の閲覧を行いやすくするWeb GUIを開発する。

この目的と評価方法は未確定であり、指導教員との相談および計算実験を通じて更新する。

## 現在のMVP範囲

1. ブラウザから検証済み入力一式をアップロードする。
2. QEでSCF計算を実行する。
3. バンド構造のための後続計算を実行する。
4. NSCF・PDOS計算を実行する。
5. 計算状態、ログ、バンド構造、PDOSをブラウザで確認する。

PDOS計算・表示はMVPの必須範囲とする。採用理由は [ADR-0001](decisions/0001-include-pdos-in-mvp.md) を参照する。

## 現在ある要件草案

より詳細なAPI、WebSocket、PBSジョブ管理、結果表示の草案は [`../webapp/REQUIREMENTS.md`](../webapp/REQUIREMENTS.md) にある。この文書は過去の案であり、採用済みの仕様ではない。MVPの実行方式は、PBSではなくmdx-server上のアプリ側待ち行列・ワーカーによる直接実行とする（[ADR-0005](decisions/0005-use-application-queue-on-mdx.md)）。

チュートリアルを基にした、検証済みZIP入力方式の具体的な画面・処理フロー案は [GUIワークフロー仕様案](gui-workflow-spec.md) を参照する。この文書も提案中である。

## 現時点での機能候補

- 計算ジョブの投入
- ジョブの進捗・失敗状態の表示
- バンド図・PDOS図の表示とダウンロード
- 計算ログの閲覧
- ジョブ履歴の閲覧

## 未決定事項

- 対象物質と扱う結晶構造の範囲（最初の検証対象はシリコン。ADR-0002を参照）
- 計算条件をどこまでユーザーに公開するか
- 認証・アクセス制御の要件
- 実行環境、待ち行列、ワーカーの直接実行に関する詳細
- GUIの有効性をどう評価するか

## 非機能面で確認が必要なこと

- 計算サーバー資源の上限と同時実行数
- 長時間ジョブの永続的な監視・復旧
- ZIP展開時の安全性、アップロードサイズ、ユーザー入力の検証
- VPN利用時のアクセス方式
