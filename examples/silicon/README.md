# シリコン計算例

このディレクトリは、最初の学習・検証対象としてシリコンの入力例、実験記録へのリンク、結果の読み方を集めるための場所である。

シリコン用の入力一式は、結晶構造のCIFからQE input generatorで作成した `PWscf.zip` を起点に用意する。今回取得した入力一式と確認記録は [`docs/experiments/silicon/`](../../docs/experiments/silicon/) に置く。具体的な作成手順は [QEバンド構造・PDOS計算チュートリアル](../../docs/tutorials/tutorial-qe-band.md) を参照する。

まだシリコン用の検証済み入力・実験結果は追加していない。
