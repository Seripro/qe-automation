# MVPまでのマイルストーン

## MVPの完成条件

検証済み `PWscf.zip` をブラウザから登録し、シリコンについて **SCF → バンド構造 → PDOS** をPBSで実行できる。進捗・ログ・バンド図・PDOS図をブラウザで確認できる。

計算が正常終了したことと、結果が物理的に妥当であることは分けて確認する。

## 1. シリコン計算を理解・再現する

- シリコンのCIFからQE input generatorで `PWscf.zip` を作成する。
- ZIPに含まれる `pwscf.in` の条件を確認し、擬ポテンシャルと収束条件を検証する。
- 入力の各項目と、SCF・バンド・PDOSの役割を説明できるようにする。
- CLIでSCF → バンド → PDOSを実行し、実験記録に残す。

**完了:** シリコンの入力・出力・実行手順が記録され、結果を最低限説明できる。

## 2. 実行環境とジョブ処理を確定する

- PBSの投入方法、状態取得、キャンセル方法を確認する。
- QE、SeeK-path、プロット環境、作業ディレクトリの条件を確認する。
- 既存スクリプトを、Webアプリから呼び出す処理単位へ整理する。

**完了:** Webアプリが何を実行・監視すればよいかを仕様として説明できる。

## 3. バックエンドを作る

- ZIPの検証と安全な展開を実装する。
- ジョブの作成、状態保存、PBS投入、ログ取得を実装する。
- SCF → バンド → PDOSを失敗時に停止できるワークフローとして実装する。

**完了:** API経由でシリコン計算を投入し、完了・失敗・ログを取得できる。

## 4. フロントエンドを作る

- ZIP投入画面を作る。
- ジョブの進捗・ログ表示を作る。
- バンド図・PDOS図・ダウンロード画面を作る。

**完了:** ブラウザだけで計算投入から結果確認まで行える。

## 5. MVPを通しで検証する

- シリコンでE2Eテストを行う。
- 正常系、入力不備、PBS投入失敗、SCF・バンド・PDOS失敗を確認する。
- 操作手順、ログ、結果の分かりやすさを見直す。

**完了:** MVPの完成条件を満たし、制約・未解決事項・次の改善案が記録されている。
