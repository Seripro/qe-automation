作成した処理は、次の一本の流れです。

```text
SCF：安定な電子密度を求める
  ↓
バンド：特定のk点経路でエネルギーの変化を見る
  ↓
NSCF + PDOS：エネルギーごとの状態数と軌道成分を見る
```

## 1. 各スクリプトがしていること

### `qe_mdx_scf_openmp.sh`：後続計算の土台を作る

これは「Siの構造・擬ポテンシャル・計算条件を入力として、電子が最も安定に分布する状態」を求めるスクリプトです。

主な処理は以下です。

- `PWscf.zip` を新しい作業ディレクトリへコピーして展開する
- `pwscf.in` とSi擬ポテンシャルの有無を確認する
- `pw.x -in pwscf.in` を実行してSCF計算する
- `scf.out` に `JOB DONE` があること、`out/aiida.save` ができたことを確認する
- 使用した入力ZIPのハッシュ値、QEの版、開始・終了時刻などを `run-metadata.txt` に保存する

SCFの重要な出力は、全エネルギー、収束状況、フェルミ準位、そして後続計算が再利用する `out/aiida.save/` です。今回のフェルミ準位は `6.4775 eV` と記録されています。

### `qe_mdx_band_openmp.sh`：電子のエネルギーが進行方向でどう変わるかを調べる

バンド構造では、SCFで確定した電子密度を使い、結晶中の電子状態のエネルギーを、特別なk点経路に沿って計算します。

- SCFが完了済みで、再始動データがあることを確認する
- `scf.out` からKohn–Sham状態数とフェルミ準位を取り出す
- `pwscf.in` をコピーして `band.in` を作る
  - `calculation = 'bands'` に変更
  - 非占有状態も描けるよう `nbnd` を設定（今回は16）
  - SCF用の一様なk点メッシュを削除
- SeeK-pathで高対称k点経路 `Γ → X → U | K → Γ → L → W → X` を生成し、`band.in` に加える
- `pw.x` でバンド計算し、`bands.x` で描画用データ `bands.out.gnu` に整形する
- `plot_bands.py` で、全エネルギーからフェルミ準位を引いたバンド図を作る

ここでのポイントは、SCFのk点が「電子密度を正しく求めるための網目状の点」であるのに対し、バンド計算のk点は「図として見やすい代表的な経路」であることです。

### `qe_mdx_pdos_openmp.sh`：どのエネルギーに状態があり、それが何由来かを調べる

PDOSでは、電子状態をエネルギーごとに数え、さらに「Siのs軌道らしさ」「Siのp軌道らしさ」のように分解して見ます。

- SCFの完了と再始動データを確認する
- `pwscf.in` から `nscf.in` を作る
  - `calculation = 'nscf'` に変更
  - `nbnd = 16` を設定
  - `occupations = 'tetrahedra_opt'` に変更
- `pw.x` でNSCF計算を実行する  
  → SCFで求めた電子密度を更新せず、その密度を使って状態のエネルギーを計算する段階です。
- `projwfc.x` で全DOSと原子・軌道別PDOSを出す
- `sumpdos.x` で、2個あるSi原子の同種軌道を合算する
  - `pdos_Si_s.dat`
  - `pdos_Si_p.dat`
- `plot_pdos.py` で全DOS・Si s・Si pを同じ図に描く

つまり、バンド図が「状態のエネルギーがk点によってどう動くか」を示すのに対し、PDOS図は「各エネルギーに状態がどれだけあり、それがどの軌道に近いか」を示します。

## 2. バンド図の読み方

![バンド図](docs/experiments/silicon/output/bands.png)

- 横軸：結晶中の電子の波数を表すk点の経路  
  `Γ`, `X`, `L` などは高対称点の名前です。横軸の距離自体を物理的な長さとして解釈するものではありません。
- 縦軸：電子状態のエネルギー
- 青線：許された電子状態（バンド）
- 横の破線 `0 eV`：フェルミ準位  
  元のエネルギーからSCFで得たフェルミ準位 `6.4775 eV` を引いて、比較しやすくしています。

最初は次の順に見るとよいです。

1. `0 eV` を横切る青線があるか  
   あるなら、その計算では金属的な状態が示唆されます。ないなら、半導体・絶縁体の候補です。

2. `0 eV` の下側で最も高いバンド（価電子帯上端）を見る  
   主に電子が占有している側です。

3. `0 eV` の上側で最も低いバンド（伝導帯下端）を見る  
   電子が励起されたときに入る候補の状態です。

4. その間にバンドがないエネルギー範囲があるかを見る  
   これがバンドギャップです。

今回のSi図では、`0 eV` を横切る線は見えず、価電子帯上端はおおむねΓ点付近、伝導帯下端はX点付近に見えます。そのため、少なくとも図の見た目としては「ギャップを持つ半導体らしい」「価電子帯上端と伝導帯下端が異なるk点にある間接ギャップらしい」という観察ができます。

ただし、現段階ではギャップ値を確定したとは言えません。カットオフ、k点、`nbnd` などの収束確認と、計算条件に対応する文献値・基準値との比較が必要です。

## 3. PDOS図の読み方

![PDOS図](docs/experiments/silicon/output/pdos.png)

- 横軸：フェルミ準位を基準にしたエネルギー
- 縦軸：DOS（そのエネルギー付近に存在する電子状態の多さ）
- 黒：全DOS
- 青：Si s軌道へ投影したPDOS
- 橙：Si p軌道へ投影したPDOS
- 縦の破線：フェルミ準位、つまり `0 eV`

見る順番は次の通りです。

1. `0 eV` 付近の黒線を見る  
   黒線がゼロに近ければ、その近傍に電子状態が少ない、つまりバンドギャップに対応する領域です。今回の図でもフェルミ準位近傍で全DOSがほぼゼロであり、バンド図の観察と整合します。

2. 価電子帯側（`0 eV` より左）と伝導帯側（右）を分けて見る  
   左は主に占有状態、右は主に非占有状態として読めます。

3. 色線を黒線と比べる  
   橙が大きいエネルギー領域は「その状態にSi p軌道らしい成分が多い」ことを示します。今回の図では、価電子帯上端近傍はsよりpの寄与が目立ちます。伝導帯側にもp成分が大きい領域があります。

ここから言える定性的なことは、「Siの価電子帯・伝導帯は、単一の軌道ではなくs/p成分が混ざった状態であり、特に価電子帯上端付近ではp成分が主要に見える」です。これはSiの共有結合的な電子状態を理解する入り口になります。

一方、PDOSの線の高さだけで「その軌道に電子が何個ある」とは直接言えません。状態数を議論するにはエネルギー範囲で積分する必要があり、投影方法・擬ポテンシャル・計算条件にも依存します。

## 4. 二つの図を組み合わせる意味

| 図       | 分かること                                        | 今回のSiでの観察                                               |
| -------- | ------------------------------------------------- | -------------------------------------------------------------- |
| バンド図 | ギャップの位置、価電子帯・伝導帯がどのk点にあるか | Γ付近の価電子帯上端とX付近の伝導帯下端の間にギャップらしき領域 |
| PDOS図   | 各エネルギーの状態の多さ、原子・軌道成分          | フェルミ準位近傍のDOSは小さく、価電子帯上端付近はp成分が目立つ |

要するに、バンド図は「電子状態が結晶中の方向によってどう変わるか」、PDOS図は「その状態が何由来か」を見る図です。両方がフェルミ準位近傍で状態の少ない領域を示しているため、今回の結果は少なくとも定性的には互いに矛盾していません。
