# ADR-0002: 最初の検証対象をシリコンにする

- 日付: 2026-11-17
- 状態: 採用
- 決定者: 研究者（ユーザー）とAIアシスタント
- 関連資料: [学習ロードマップ](../physics/00-learning-roadmap.md)、[第一原理計算とDFT](../physics/01-first-principles-and-dft.md)

## 背景・課題

MVPの計算フローを検証し、物理学習とGUIの結果表示を進めるため、最初に扱う物質を決める必要があった。

## 検討した選択肢

### 選択肢1: シリコン

- 基本的な半導体として、SCF、バンド構造、PDOSの学習対象に適している。
- 入力例や既知の性質との比較を探しやすいと見込まれる。

### 選択肢2: チュートリアルのMgB₂

- 研究室チュートリアルとの直接対応を取りやすい。
- 最初の物理学習対象として、金属的性質や複数元素・軌道の扱いが増える。

## 判断

**最初の検証対象をシリコンにする。**

MgB₂は、シリコンで計算フローとGUIの基本動作を確認した後の比較・拡張対象とする。

## 理由

- SCF、バンド構造、PDOSの基本概念を段階的に学べる。
- GUIで表示する結果の基準例として扱いやすい。

## 影響・トレードオフ

- 最初に用いる入力例、擬ポテンシャル、収束条件、比較対象をシリコン向けに明確化する必要がある。
- MgB₂向け既存チュートリアルとの違いは、後の実験記録で区別する。

## 後で見直す条件

- 研究室の計算環境で利用可能なシリコン用擬ポテンシャルや入力例に問題がある場合。
- 教員から異なる対象物質を指定された場合。
